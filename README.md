# WeFortuneAsset

WeFortuneAsset is a bilingual, multi-page asset-management website built with
plain HTML, CSS, and JavaScript.

## Languages

- American English: `/en-us/`
- Brazilian Portuguese: `/pt-br/`

## Local preview

Open `index.html` directly, or run a static web server from the project folder:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Pages

- Home
- About Us
- Core Services
- Why Choose Us
- Investment Approach
- Global Strategy
- Management Team
- Contact Us

The website includes responsive layouts, localized SEO metadata, alternate
language links, a sitemap, robots directives, favicon assets, and a web app
manifest.
